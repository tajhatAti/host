Add a Render runner

  1. Render → New Web Service → connect this GitHub repository.
  2. Set Root Directory to runner, Runtime to Docker, and deploy from runner/Dockerfile.
  3. Generate a new secret below. Add that exact value to the new service as RUNNER_SERVICE_SECRET. Each admin-managed runner may use its own secret.
  4. Add PUBLIC_BASE_URL with the new runner's own https://…onrender.com URL, then deploy.
  5. Open RUNNER_URL/health. Continue only when it returns JSON with "status":"ok".
  6. Paste the base service URL (no /health) and the same secret here, then select Test & add runner.
